To publish free:
1. Create a GitHub account.
2. Create a new public repository, e.g. suggu-portfolio.
3. Upload all files from this folder.
4. In Settings > Pages, choose Deploy from branch > main > /(root).
5. GitHub will give you a free website URL.

Before publishing, replace/add your LinkedIn and YouTube links in index.html if needed.
The showreel button currently points to the Instagram reel supplied by the user.
